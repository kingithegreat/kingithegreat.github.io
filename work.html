How it is built

The interesting part of this portfolio is not any single project — it is that one person can keep 9 games and a desktop app moving at once. That comes down to three decisions.

Engine-free game logic

Every game's rules live in one module with zero Roblox API calls, so the entire logic layer runs under a plain Luau CLI. That is what makes a headless pipeline possible: the tests below run in CI in seconds, with no editor and no game client.

A written contract, not conventions

The portfolio has a single canonical engineering contract covering architecture invariants, the local CI mirror, and which operations require a human. Every repo points at it instead of restating it.

Publishing is a guarded operation

Pushing to main on a live game deploys to players, so agents and tooling branch and open a pull request; a human merges. The MCP server enforces the same rule server-side.

Roblox games

9 games, one shared CI platform. Each is a Rojo/Luau project whose game logic lives in a single engine-free module, so the whole rules layer runs and is tested on a plain CLI with no Roblox in the loop. Built, tested and published headlessly — no Studio in the pipeline.
